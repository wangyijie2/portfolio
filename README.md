# 机器人结构设计项目记录

该仓库整理机器人结构设计、机构开发与仿真实践中的项目资料，涵盖企业项目和个人设计实践。

## 项目内容

- 双电池充电仓：钣金结构、电池导向、散热与电子元器件集成。
- 折叠式机器人腿部：关节模组与轴承选型、连杆结构及走线设计。
- 五指连杆灵巧手：连杆机构、样机装配及多舵机控制。
- 四足机器人：总体结构、运动学分析与动力学仿真。
- 柔性五指夹爪：行星滚柱丝杠传动、柔性夹持及连杆拓扑优化。
- SO-ARM101双臂：开源方案复现、遥操作、示教采集与模仿学习实践。
- 其他设计：控制器外壳、散热结构、桌面机械臂及有限元分析。

## 项目说明

SO-ARM101案例为开源方案复现，原始项目为 [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100)。五指连杆灵巧手的机械模型与控制代码整理于 [Easyhand](https://github.com/wangyijie2/Easyhand)。
